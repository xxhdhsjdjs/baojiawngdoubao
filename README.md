# 报价王 · 在线报价单制作

基于参考报价单模板，快速生成、编辑、计算、保存并导出专业报价单的**纯前端单文件应用**。无需安装、无需后端，浏览器打开即可使用。

## 功能特性

- **报价内容编辑**：报价明细支持增项、减项、复制、删除、拖拽排序；序号自动重排
- **双输入方式**：每个输入框都支持键盘打字 + 语音输入（浏览器 Web Speech API，中文识别自动填入当前单元格）
- **自动计算**：小计 = 数量 × 单价；合计自动汇总；支持折扣、税金、运费、总价公式（可在「金额设置」中开启）；金额统一千分位 + 两位小数，实时更新
- **标准附表**：参考报价单的「开关插座点位及费用明细」「材料品牌型号备注」已内置为标准模板库，可选用、可编辑增删、可另存为自定义模板
- **备注与条款**：内置 9 条默认条款（工期、质保、结算审核、付款节点、工程增项、安全、税费等），可一键启用/取消、自由编辑、多套模板切换
- **保存与导出**：草稿自动保存（localStorage）、打印 / 另存 PDF、导出 Excel（多工作表）、生成分享链接（数据压缩存于 URL，无需服务器）
- **撤销/重做**：100 步历史栈（Ctrl+Z / Ctrl+Y）

## 快速开始

1. 用 Chrome / Edge 浏览器打开 `报价王.html`
2. 首次打开即载入参考报价单模板，可直接编辑
3. 语音输入：点击任意输入框右侧的麦克风按钮，说出内容自动填入
4. 导出：顶部工具栏「打印/PDF」「Excel」「分享」

> 提示：语音输入需要 Chrome / Edge 浏览器并允许麦克风权限；Excel 导出首次使用需联网加载组件（失败自动降级为 CSV）。

## 技术说明

- 纯原生 HTML/CSS/JavaScript，单文件自包含，无构建工具、无依赖框架
- 数据持久化：浏览器 localStorage（当前报价单自动保存 + 草稿列表 + 自定义模板）
- 语音输入：Web Speech API（`SpeechRecognition`，`zh-CN`）
- Excel 导出：SheetJS（CDN 按需加载，离线降级 CSV）
- 分享链接：JSON 压缩（`CompressionStream deflate-raw`）→ base64url 编码存入 URL `#share=`，打开即恢复

## 字段基准

页面结构与字段（序号、项目名称、施工内容及说明、数量、单位、单价、金额、附表、备注条款、签字区等）均解析自参考报价单，未臆造字段。
